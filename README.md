# Ukemeny og handleliste

Genererer en ukemeny basert på mine utvalgte retter og bygger en samlet handleliste automatisk. Handlelista kan kopieres med ett klikk og limes inn i ønsket handleliste-app eller notat.

**Live demo:** https://magnushansenm.github.io/ukemeny/

## Funksjoner
* **Ukemenygenerator:** Velg hvilke dager du vil planlegge, bytt ut enkeltdager, eller lås retter du vil beholde (med fast taco på fredag så klart).
* **Skalert handleliste:** Mengdene justeres etter antall personer og grupperes etter butikkavdeling.
* **Basisvarer og ekstravarer:** Flytt basisvarer over på handlelista ved behov, legg til egne varer, og kryss av det du allerede har. Det man krysser av på lista blir ikke med når man trykker kopier.
* **Lokal lagring:** Husker ukemeny, valg og avkrysninger i nettleseren (`localStorage`).
